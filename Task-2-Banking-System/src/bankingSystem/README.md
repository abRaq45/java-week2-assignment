# Banking System

A console-based Java banking application that supports savings and current accounts and provides common banking operations.

## Features

- Create Savings Account
- Create Current Account
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- View transaction history
- Generate account statement
- Input validation
- Exception handling
- Minimum balance and transaction rules

## Technologies Used

- Java
- OOP
- Inheritance
- Polymorphism
- Abstract Classes
- Exception Handling
- HashMap
- ArrayList
- Scanner
