# Student Management System

A console-based Java application for managing student records.

## Features

- Add student records
- Display all students
- Search student by ID
- Search student by name
- Update student grade and subjects
- Delete student records
- Calculate class average grade
- Save and load student data using file handling
- Input validation

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner
- File Handling
