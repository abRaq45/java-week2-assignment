# Java Week 2 Assignment

This repository contains the Java Development Week 2 assignments completed as part of the internship program.

## Tasks

### Task 1 - Student Management System

A console-based Java application for managing student records.

**Features:**
- Add student records
- Display all students
- Search student by ID
- Search student by name
- Update student details
- Delete student records
- Calculate class average
- File handling for saving and loading student data
- Input validation

**Technologies:**
- Java
- OOP
- ArrayList
- Scanner
- File Handling

---

### Task 2 - Banking System

A console-based Java banking application supporting different types of bank accounts and common banking operations.

**Features:**
- Create Savings Account
- Create Current Account
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- View transaction history
- Generate account statement
- Exception handling
- Account and transaction validation

**Technologies:**
- Java
- OOP
- Abstract Classes
- Inheritance
- Polymorphism
- HashMap
- ArrayList
- Exception Handling

---

### Task 3 - JDBC Integration

A Java application that connects to MySQL using JDBC and performs CRUD operations on student records.

**Features:**
- MySQL database connection
- Create students table
- Insert student records
- Display student records
- Update student records
- Delete student records
- PreparedStatement
- SQL exception handling
- DAO pattern

**Technologies:**
- Java
- JDBC
- MySQL
- Maven
- PreparedStatement
- DAO Pattern
